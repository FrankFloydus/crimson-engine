# Material node authoring conventions

This guide applies when adding or modifying Material Editor nodes. The CPU material graph is authoritative; renderer preparation and editor presentation are separate consumers. Follow the ownership and history contracts in [ENGINE_ARCHITECTURE.md](ENGINE_ARCHITECTURE.md#editor-ui-conventions).

## Properties and inline controls

- Put the editable node name at the top of the inspector. Do not add a single-field **Node** header. Use `SeparatorText` for a short flat group and unframed `TreeNodeEx` rows for expandable subsections. Reserve framed headers for substantial top-level groups.
- Expose the node's frequently edited value inside the node. The inspector adds detailed settings; it must not become a second source of values. Scalar has a direct value control, Vector2 has X/Y, Constant has a clickable swatch, Texture 2D has its image and Sample Type, and UV has mapping and transforms.
- For an input with an authored fallback, show the fallback editor beside the disconnected pin. Hide that editor when connected, retaining its authored value so disconnecting restores it. This includes Multiply operands, Output defaults and UV Scale XY/Offset XY.
- Inactive Output pins remain visible and dimmed, with their connections retained. Reject new connections to inactive pins. Use central shader-model definitions for activation, labels and types rather than repeating rules in widgets.
- Inline controls, property controls, asset assignment and graph commands use the existing `MaterialDocument` transaction API. A drag is one command. Escape restores its exact starting values. Selection, navigation, expansion and node-preview targets are transient.
- Draw popup contents after suspending the node canvas. Convert the originating control's bounds to screen coordinates once, anchor dropdown lists beside that control, and keep them within the viewport work rectangle. Do not call a raw `ImGui::Combo` inside the transformed canvas. Opening or cancelling a dropdown does not start a document transaction; accepting a value creates one undo command.
- Preserve ImGui's default global theme, font and sizing. Never put tutorials, implementation explanations or redundant action buttons in the inspector body. Use a short tooltip for an operational constraint.

## Color and numeric controls

- Reuse `HdrColorEditor`: a disclosure row and full clickable swatch, with optional expanded linear channel values. Do not show a second RGB editor beside a picker or add an EV slider/derived multiplier label.
- Stored RGB is linear HDR. Merely viewing, expanding or opening the picker must not alter it. Ordinary swatches use linear-to-sRGB conversion; HDR swatches normalize display brightness only and show an HDR marker. Popup hue edits preserve existing HDR strength, while numeric channels allow direct HDR entry.
- Material emission strength is explicit Scalar/Multiply graph math. Particle Brightness is the existing independent multiplier with Constant/Random Range/Curve modes. Never normalize or rebake old colors into another parameter.
- Particle Color reads the emitter's evaluated color, Brightness and Opacity. These attributes affect the material only through connected Particle Color outputs; never multiply the final material by them again. Its RGB and R/G/B/A outputs are source values, so the node has no color picker or editable color default. Ordinary mesh and node previews supply white for this source.
- Constant alpha is labeled **Alpha** and affects coverage only through an explicit graph connection. Particle coverage controls are labeled **Opacity**. Brightness edits never change alpha.
- Scalar slider ranges are soft gesture ranges: numeric entry outside the range remains available. Enforce finite values and the owning property's actual validation limits separately.

## Typed pins and textures

- A central presentation definition supplies names, category accents, pin colors and preview capability. Node accents describe categories. Output connectors and wires describe resolved value types. Empty image inputs accepting Scalar/RGB/RGBA use a two-color grayscale/color connector; every connected input uses the incoming wire's actual type color, including fixed receivers such as Height. `materialGraphInputMixedImage` owns accepted-family metadata independently of connection state. R/G/B/A and X/Y outputs are Scalar connectors. Empty Height, mask, adjustment-strength, Mapping and Normal inputs show their fixed receiving type; connected glyph color does not change that receiving contract. Numeric arithmetic can also accept Vector2 and is not labeled as a mixed image. While wiring, highlight validated compatible targets, distinguish a conversion and dim incompatible targets. Do not create separate Color/Grayscale versions of adaptable filters.
- Keep custom node names and search aliases when display names change. Use **Scalar (1D)**, **Vector2**, **Constant**, **Multiply**, **Add**, **Lerp**, **Power**, **Clamp**, **Desaturation**, **Contrast**, **ContrastRGB**, **HueShift**, **Grunge**, **Texture 2D**, **UV**, **Panner**, **Time**, **Particle Color**, **Radial Gradient** and the model-specific Output name. The former Saturate name is a search alias for Clamp; preserve its existing numeric kind and authored names.
- Texture **Sample Type** is Color, Linear Data or Normal. Filtering/wrapping belong to Sampler properties, not Sample Type. Roughness/metallic/AO are linear channel data; normal decoding and strength retain their specialized semantics.
- Texture 2D has one clickable image preview/drop target. Color and Linear Data show one composite **Image** (RGBA) output plus R/G/B/A; existing RGB links retain their original endpoint, shown while linked or previewed. Texture pickers show small images beside names and request thumbnails only for visible rows.
- Authoring connects compatible endpoints directly, including RGB/RGBA to fixed Scalar inputs; never insert a conversion node automatically. The receiving Scalar retains the established first-component (R) rule, with a small R badge for an implicit channel read. A fully desaturated RGB branch has equal channels, so `Color Texture → Desaturation → Levels → Height` works directly without another node. Explicit R/G/B/A connections retain their selected channel. Existing authored adjustment/conversion nodes remain ordinary graph content. Mapping and Normal remain strict types, and Vector2 compatibility and Multiply inference are unchanged.
- Texture fields include adjacent picker, thumbnail/name, clear and drop behavior. Borrow AssetLibrary thumbnail resources only for UI submission. Never serialize GPU or ImGui handles.
- Keep node titles and texture names within the node's content width. Ellipsize long text on one line without splitting UTF-8 characters, expose the full name on hover, and keep pin columns aligned to the node edges. Asset names must not resize the node independently of its pin layout.
- Canvas drops convert screen position to graph position exactly once. A batch creates its first node at that position and offsets later nodes by 32 graph units. Validate the entire operation before mutation; one drop is one undo command.
- Vector2 arithmetic accepts Scalar or Vector2, not RGB, Mapping or Normal. Mapping remains a distinct type. UV Scale XY/Offset XY accept uniform constants, arithmetic and Time; texture-driven transforms are invalid. Use the shared mapping evaluator and the submitting view's material-time context for shader packets and streaming demand; legacy transport and thumbnails use deterministic time zero.
- Radial Gradient has an optional UV mapping input and a scalar Value output. Disconnected UV uses identity UV0. It evaluates `max(1 - dot(uv * 2 - 1, uv * 2 - 1), 0)^2`, preserving the former default sprite's soft-disc shape as explicit graph content. It has no hidden radius, strength or fallback color controls; use UV transforms and ordinary Multiply nodes. It is available to every material.
- Clamp clamps one scalar input to 0–1 and exposes a scalar Value output. Its disconnected Value editor accepts any finite value, preserves that authored value while connected, and reappears after disconnection. Use the ordinary math accent, scalar preview and transaction behavior. It remains a uniform expression when its source is uniform. Its kind value and operation retain the former Saturate node, including legacy particle migration before particle-alpha and radial modulation to preserve the original order of operations and old coverage values above one.

## Image adjustments and procedural grunge

- Desaturation, Contrast, ContrastRGB and HueShift accept a scalar or RGB Input plus a scalar adjustment input, with retained inline disconnected defaults. Scalars broadcast to RGB. Reject Vector2, Mapping and Normal inputs. Desaturation, ContrastRGB and HueShift expose RGB and R/G/B outputs; Contrast exposes scalar Value and equivalent grayscale RGB.
- Evaluate adjustments in linear RGB without an output clamp. Use luminance `dot(rgb, (0.2126, 0.7152, 0.0722))`. Desaturation defaults Saturation to 1 and evaluates `gray + (rgb - gray) * saturation`: 0 is grayscale and values above 1 increase saturation. Contrast defaults to 1 and evaluates `0.5 + (luminance - 0.5) * contrast`; ContrastRGB applies that equation per channel. Both use a fixed 0.5 pivot, and 0 produces flat 0.5 gray.
- HueShift uses a signed Degrees input, default 0, with a soft -180–180 gesture range and unrestricted finite numeric entry. Wrap degrees modulo 360; 120 rotates red to green and 360 preserves the source. Rotate HSV hue while retaining value and saturation, including linear HDR strength; grayscale stays unchanged. Do not add a color picker or a second hue representation.
- CPU uniform evaluation and generated shaders share adjustment equations. Adjustments stay uniform only when every connected input is uniform; varying inputs remain varying. Parameter changes use existing value updates without changing shader topology. Provide ordinary color/grayscale previews and one transaction per gesture.
- Grunge combines dirt specks, stains, scratches, leaks and noise into one deterministic canonical 1024×1024 linear RGBA8 texture, with identical grayscale RGB channels and opaque alpha, available to every material. Independent layer opacity controls determine their contributions to that image; zero removes a layer's contribution. Its optional UV Mapping input uses UV0 when disconnected and supports the same UV0/UV1/local/world triplanar contract as Texture 2D. Value and RGB expose the same sampled grayscale pattern in 0–1. Each active Grunge consumes one sampler from the shared twelve Texture 2D/Grunge slots. No external bitmap, separate catalog entry or project image file is required.
- Grunge defaults to Seed 0, Tiling 1, Coverage 0.5, Disorder 0.5 and Detail 0.5. Layers defaults are Base Noisiness 0.55, Dirt Specks Opacity 0.62, Stains Opacity 0.35, Scratches Opacity 0.84, Leaks Opacity 0, Sharpen 0.63, Large Variation Intensity 0.9 and Invert Dirt false. Seed accepts 0–65,535, Tiling 1–64, and all remaining numeric controls 0–1. Put the common controls inline and in properties; use an unframed Layers disclosure for the additional controls. All use existing document transactions and Escape cancellation.
- Generator settings select a content-keyed CPU image and regenerate asynchronously through ResourceManager workers. TextureStreamer owns main-thread GPU publication, mips, display copies and leases; keep the previous coherent image/material packet until the replacement is ready. Changing generation settings must not compile a new shader variant. Apply Tiling and Mapping when sampling, outside the generated-image key, so those edits do not rebake pixels. Advance the generator revision when its pixel equations change.
- Show a square generated image inside the Grunge node. Its explicit Start Previewing/Value/RGB preview follows the viewport's 2D/3D mode; retain the material's independent 3D geometry choice while showing a flat image. In 2D, Value displays raw numerical grayscale, while RGB uses a single sRGB display conversion. Both derive from the same linear pixels used by roughness and other material connections. Reuse the canonical image for the node image and flat preview; retain leased last-good images while generation is pending, and request inline images only when visible. Image presentation and Layers expansion never dirty the document.

## Arithmetic, time and scrolling

- Add defaults to A = 0 and B = 1. Lerp defaults to A = 0, B = 1 and Alpha = 0.5, without clamping Alpha. Numeric operations retain scalar broadcasting and reject mixing Vector2 with Color, Mapping or Normal. Power defaults to Base = 0 and Exponent = 2; it returns zero for bases at or below `2.980233e-8` and otherwise evaluates `pow`. CPU uniform evaluation and generated shaders use the same rule.
- Panner consumes and returns Mapping. Disconnected Coordinate uses UV0, with UV1 available in properties. Speed defaults to zero; disconnected Time uses game seconds. Fractional Part wraps only `time * speed`, before adding the displacement, and never wraps the source coordinates. Connected mappings preserve UV set, triplanar mode and the existing normal reconstruction contract. Time and Speed inputs must be uniform expressions.
- Time exposes Ignore Pause and an optional nonnegative Period. Period zero stops its output at zero. Scene materials animate in Edit mode; Play time starts at zero and advances with accepted fixed ticks. Material and particle previews use their own transient clocks; thumbnails evaluate at zero. Elapsed time is never serialized or published as a material edit.
- Runtime-dependent mapping rows are evaluated at submission. Shader topology and authored material signatures remain stable as time advances. Color, shadow and particle passes use one world-frame context; asynchronous picking retains the displayed frame's context. Only time-dependent Mask coverage invalidates cached shadow silhouettes.
- Graph schema v13 introduced optical Output inputs and the Refraction setting, and v14 appended Pixelization, Posterization and Dither. Schema v15 appended Kuwahara, Gradient Map and Color Range Mask. Schema v16 appends Detail Balance; schema v17 adds Decal shading and channel-opacity pins; schema v18 adds Metallic and Metallic Opacity decal inputs. Schema v19 appends Blend shading, Material Reference and the Surface/Base/Red/Green/Blue pins. Current schema v20 adds optional Material Reference layer controls and its scalar Height input, preserving all earlier numeric identities. Ordinary graph materials remain native v6 and dedicated Blend recipes use native v7; graph readers accept schemas 1–20 and convert older Grunge style settings to layer values in memory. Save writes only the current representation. Preserve node/pin kind values, IDs, links and history. Loading never rewrites a file.

## Blend material authoring

Blend materials use a dedicated layer editor and native material v7 recipe. Ordinary Lit, Unlit and Decal assets retain the graph editor and native v6 writer. New Blends have two enabled layers and an optional third. A migrated fourth layer remains available with its original identity and coverage. The derived Base/Red/Green/Blue Surface graph is renderer transport; it is never a second authored representation or an alternate editor.

Each layer chooses **Source → Inline** or **Existing Material**. Existing sources must be direct Lit/Opaque materials without nested material references. Their tessellation may remain enabled: Blend contribution consumes surface channels and retained Height while omitting child geometric displacement. Source materials and maps stay shared and unchanged. Inline channels use Value or Texture; Roughness, Metallic, Normal and Height also support Generated recipes. Scalar texture channels use explicit component selection and Linear Data; color channels decode color once, and encoded normals follow the existing normal conventions.

Generated recipes read another raw channel in the same layer, before that layer's appearance adjustments. Validate the complete dependency graph and reject self-reference and indirect cycles. Retain raw sources independently of color/roughness/metallic adjustments so a generated roughness map does not change when the artist merely tints the layer. Persist recipes and source references, including inactive sources; generated images remain disposable cache entries rather than authored PNG files. Existing custom Height expressions and detached references from older graphs remain preserved internally and participate in reference/deletion policy.

Channel previews target the evaluated channel after adjustments, for Existing and Inline layers alike. Base Color Tint/Brightness/Contrast/Saturation, Roughness/Metallic Brightness/Contrast, Normal Strength/Flip Y, AO Strength and Emission Intensity update the displayed result during a gesture. Source selection, recipe changes and numeric edits share ordinary MaterialDocument transactions, exact cancellation and independent undo/redo. Publish only committed immutable snapshots to other consumers while the owning preview follows the live draft. Save As gives the complete recipe and retained expressions a new asset identity.

Height is editable without tessellation and changes material transitions without moving geometry. Existing layers inherit child Height/default 0.5 unless a retained custom layer branch overrides it. **Height → Scale** defaults to 1 and retained authored scales support [-16,16]; **Height → Midpoint** is [0,1], default 0.5. Painted-layer **Transition → Mode** defaults Smooth; Height enables relief-based coverage. **Height Influence** is [0,1], default 1, and **Softness** defaults 0.2. Disabled Height branches retain sources but consume no runtime samples unless an active painted layer requests height blending.

Normal/Roughness/Color/Metallic/AO influences default to 1 in [0,1]. Zero retains the accumulated underlying property; one replaces it with the incoming property at full painted coverage. Roughness scaling adjusts the incoming value independently of its influence. Layer mapping supports UV0, UV1 and Local/World Triplanar with linked scale, rotation and offset. It changes runtime sampling without modifying source materials or rebaking unchanged cached-image pixels. Layer authoring belongs in the Blend editor; the Vertex Paint Tool owns brushes and coverage. Earlier scene occurrence overrides remain effective and retain their slot/material guards, history and saved values.

Blend composes Base, Red, Green and retained Blue in that order. Original normalized paint weights become cumulative overlay alphas, so disabled height and neutral controls retain the weighted surface result. Height blending biases each overlay's alpha using underlying and layer relief while preserving exact zero/full coverage and finite results. Normalize the final normal and evaluate lighting once; imported vertex color remains an independent tint applied once. The parent controls culling and fog. Active source expansion preserves cached-image provenance, shares twelve runtime samplers and 208 vec4 rows, and supports the same preparation in material previews, thumbnails, Scene/Game and the cache commandlet. Transparency, final Blend geometric tessellation and displacement painting remain outside this domain.

## Common materials and particle attributes

- Materials have Shader Model and Blend Mode, without an exclusive Surface/Particle usage selector. Mesh and particle fields select Lit/Unlit materials from the shared catalog. Decal assets select the explicit Decal shader domain. Renderer capabilities and diagnostics must not rewrite the assigned graph or infer a material domain from its blending, name or texture.
- **Height** is a scalar Output input, appended without renumbering existing pins. Lit materials keep Height editable with tessellation disabled so Blend layers can inherit it. Ordinary surface rendering demands the branch only when **Material → Tessellation** is enabled; inactive Height retains its link/default without active sampler or shader work. Unlit displacement retains its existing tessellation activation. Disconnected Height defaults to 0.5 and uses the ordinary inline/default-input transaction path. Height maps use explicit **Linear Data** sampling; RGB-to-scalar still selects R. **Displacement Amount** defaults to 0.1 mesh-local units before object scaling, **Midpoint** to 0.5, **Tessellation Factor** to 8 (integer 1–64), and **Advanced → Height Texture LOD** to 0 (0–16). Displacement is `normal * (clamp(height,0,1)-midpoint) * amount`; signed Amount reverses relief. Enable changes shader topology; control/value edits retain compatible programs. DX12 mesh passes use hardware tessellation; DX11 and particle sprites use ordinary geometry without rewriting the graph.
- **Receive Fog** is an Output material setting beside culling, default true for new and existing materials. It applies to Lit/Unlit and every blend mode on meshes and particles. Keep it independent of lighting, coverage, depth and shadow settings; it disables both distance and height fog. Use the same property transaction/history path as the other material settings. It changes authored values and render packets, not shader topology or node connections.
- **Refraction** is an Output material setting, default off, active only for Lit/Translucent through `materialRefractionActive`. It activates Transmission (default 1, 0–1), IOR (1.5, at least 1), Thickness (0, nonnegative world-space meters), Attenuation Color (linear RGB white, 0–1), and Attenuation Distance (1 positive world-space meter). IOR's 1–3 slider is a soft gesture range. Keep the optical pins visible and dimmed while inactive, reject new inactive connections and retain all links/defaults. Active refraction makes Specular dormant because IOR owns dielectric F0; disabling it restores the retained Specular branch. Metallic suppresses dielectric transmission. Opacity remains independent surface coverage, including reflection fading. Author optical fallback values inline and under Default inputs, using the shared color editor with a maximum of 1 for Attenuation Color. Use one document transaction per gesture and exact Escape cancellation. Runtime traversal/streaming and active signatures omit dormant optical/Specular branches; dependency retention and Save preserve them. Refraction enable changes topology; optical value edits retain compatible programs.
- Output coverage activation depends on blend mode: Opaque has neither coverage input active, Masked activates Opacity Mask, and Translucent/Additive activate Opacity. Keep the inactive values and links. A constant color alone leaves the full sprite quad covered; color alpha does not implicitly create coverage or a round shape.
- Masked is valid for both Lit and Unlit particle sprites. For animated cutout coverage, multiply the authored mask by Particle Color A before Opacity Mask. The cutoff discards the entire surface, including emission. Do not change blend mode to repair an unconnected particle alpha path.
- The protected default sprite material uses explicit Particle Color and Radial Gradient graph nodes. It is an ordinary authored graph with a protected asset identity. Save As creates an editable material. Loading an older material materializes its former implicit modulation and shape as visible nodes; do not keep an extra hidden shader branch.
- Particle Editor color, Brightness and Opacity remain emitter attributes. Keep their existing tracks and labels; a material must connect Particle Color to consume those attributes. Put any short explanation in a tooltip, never a new explanatory panel section.

## Interaction and preview

- RMB drag pans; a stationary RMB click opens context actions. Held 1/2/3/M/T plus LMB creates Scalar/Vector2/Constant/Multiply/Texture on empty canvas. Respect text entry, active widgets, popups and drag payload ownership.
- Keep Alt-click disconnection, Q straightening, F/Home framing and clipboard/group commands consistent for new nodes. Output remains unique and protected.
- Start/Stop Previewing and graph-scoped Ctrl+P operate on an explicit transient node/output target. Selection changes do not retarget preview. Deleting the target, changing documents or stopping preview restores the full material.
- Double left click on a node body previews its primary output, using the selected 3D mesh by default. The preview viewport's **2D | 3D** controls switch the same explicit target between a flat view and the selected mesh. Keep the chosen mode across node changes within the document and default new/reopened documents to 3D. Double clicking the currently previewed node stops preview, including when a non-primary output was pinned. Double clicking Output restores the full material. Pin gestures, numeric/text edits, popups and active transactions retain their input ownership.
- Static image outputs show visible-only 128-pixel inline thumbnails and, in 2D mode, a 256-pixel flat preview when pinned. Evaluate the completed authored source before area reduction; never replace a detailed procedural source with an evaluation at thumbnail resolution. Coalesce edits behind one active display job per target, publishing completed intermediate images during continuous gestures. Throttle submissions to 33 ms inline and 16 ms when pinned, rather than waiting for a quiet period after every edit. Keep the last good leased image while the newest definition is pending; hidden/closed previews release their work. Contextual Normal, Mapping and animated branches use their node shader on the selected mesh in 3D or an untumbled fixed plane in 2D. The 3D node view prepares only the selected branch rather than also preparing the full material. Images and target changes remain transient.
- Flat Scalar and Vector2 images display clamped numerical data without applying the color sRGB transfer. Color/Color4 images retain one linear-to-sRGB conversion, with independent alpha/checker composition. Keep this presentation choice outside authored pixels, generator revisions and material graph values; display cache keys must identify the current transfer policy.
- Preview Scalars as grayscale, Vector2 as XY color, RGB directly, reconstructed normals in displayable 0–1 form, and Mapping through a neutral checker. Reuse expression and mapping code. Preview recipes/resources must not publish material changes to scenes or thumbnails.
- Material preview geometry is an explicit editor choice, including Sprite alongside the mesh primitives. Never lock geometry or select a material category from connected pins, opacity, shader model or a legacy Usage field. Switching to 2D retains the stored mesh and 3D navigation, restoring both on return to 3D. Node previews remain transient; changing preview geometry or 2D/3D mode must not dirty the material.

## References and verification

The local Unreal material graph and color-struct customization informed the swatch/disclosure pattern, inline disconnected defaults, semantic node categories and drop coordinates. Unreal's `MaterialExpressionParticleColor` is a regular source expression; its material domains do not include a separate particle domain, and Niagara selects an authored default sprite material. Its preview primitive is an explicit editor choice. Crimson's Radial Gradient retains Crimson's original soft-disc equation rather than substituting Unreal's different SphereMask function. Godot's material editor informed explicit emission energy and transparent-material expectations. The readable local Adobe Substance Designer `grunge_concrete.sbs` graph informed the layered Grunge controls and composition. Crimson's generator is an independent implementation, without a claim of pixel-identical Adobe output. Crimson retains its own shader equations, normal mapping and resource ownership.

For each new node, cover CPU typing/validation, persistence and undo/redo, uniform versus structural changes, generated shader behavior, and headless ImGui interaction. Exercise inline and inspector edits against the same authored field, cancellation, connected-default restoration, pan/zoom coordinates and popup suspension. Native feature acceptance remains user-driven.

## Image and channel node foundation

See [Image and channel nodes](MATERIAL_IMAGE_NODES.md) for the thirteen added nodes,
explicit Color4/RGBA contract, artist controls and spatial sampling. Current graph schema 20 retains [Resize](MATERIAL_RESIZE.md), optical Output inputs and the reusable image operations described there, including the material stylization and painterly/color-selection nodes. Native material v6 readers accept graph schemas 1–20; node introduction versions do not change existing identities. Material ABI39 and the pass-specific source revisions follow the [shader/cache contract](MATERIAL_SHADER_STARTUP.md).
Preserve all four independently wired split outputs, transparent RGB, disconnected
defaults and per-output previews. Image adjustments preserve alpha. Noise Detail
amount is Clouds-only; never expose it as material roughness.

Resize exposes Width, Height and Filter inline and in Properties, using the same transaction and Escape cancellation rules. It preserves Scalar/RGB/RGBA type and materializes supported static UV0 branches into cached linear float images. Reject runtime or surface-dependent inputs rather than silently baking a different result. See [Resize](MATERIAL_RESIZE.md) for the sampling, cache and memory contract.

New image operations reuse the same mixed-input, direct-wire, transaction and per-output preview rules. Keep expensive spatial kernels behind the canonical static-image boundary. Image Transform samples the whole completed image; runtime mapping edits must not alter its content key. Image Input retains override/Base/Constant precedence and prunes disabled work while preserving authored references. Normal Map decodes processed linear RGB with a common source mapping into the strict Normal type. Procedural Texture family selection uses canonical per-family defaults, preserves seed/resolution and displays only active controls.

Pixelization, Posterization and Dither share one adaptable Scalar/RGB/RGBA Input and a Result of the same type. Their controls are shared between inline and Properties UI and use ordinary transactions, resets and Escape cancellation. Pixelization and Dither operate on the completed static source lattice through the existing image cache; Pixel Size and Dither Size are source-pixel units. Posterization is a point expression and remains uniform when its source is uniform. Use the post-process perceptual RGB equations, preserving alpha for Posterization/Dither and returning linear values. Dither Levels is explicit, independent of any neighboring node or Environment, and defaults to 17 for the standalone 1/16 interval. See [material stylization](MATERIAL_IMAGE_NODES.md#material-stylization) for controls and ordering.

Detail Balance and Kuwahara use shared inline/Properties controls and the existing static-image preview/cache boundary, preserving source alpha. Detail Balance has source-pixel Radius and Detail: 0 returns a Gaussian low-pass, 1 preserves the input, and 2 boosts the residual. Kuwahara is a classic four-region filter with source-pixel Radius and Mix. Gradient Map has an editable 2–16-stop linear HDR RGB ramp with stable authored stop IDs and Linear/Constant/Smooth interpolation. Reuse the common gradient widget and HdrColorEditor, with popups outside transformed canvas space, transient selection, authoritative undo/reload synchronization and exact Escape cancellation. Map scalar/luminance to RGB, retaining source alpha only through RGBA/A outputs. Stop identity metadata never affects image content keys. Color Range Mask uses a linear RGB reference color, Tolerance, Softness and Invert to produce a Scalar; its picker and numeric controls use the same document history path in both editors. See [painterly filtering and color selection](MATERIAL_IMAGE_NODES.md#painterly-filtering-and-color-selection).

Clouds Scale is feature size; other procedural frequency controls are named
Density or Tiling. Custom sizing is a transient disclosure until dimensions
change. Disconnected RGBA arithmetic defaults expose RGB and Alpha in both
inline and Properties controls. See the [property audit](MATERIAL_NODE_PROPERTY_AUDIT.md)
for pixel-based validation and intentional input-dependent behavior.


The **Decal** shader model uses a dedicated **Decal Output** node presentation. It exposes Color, Opacity, Normal, Roughness, Metallic and independent Color/Normal/Roughness/Metallic Opacity inputs. Output properties enable each affected channel. Lit-only lighting, blend, fog, refraction and tessellation controls are absent in this domain; switching shader models retains dormant authored values and links. Decal graphs use the same image and runtime node foundation, shared color controls and document transactions. Preview the graph over a neutral receiver mesh; assign it through a decal asset's Material field.
