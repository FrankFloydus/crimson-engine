# Quader Native

Standalone native C++ authoring app for Quader.

This repository will host the custom desktop editor shell. The intended shape is:

- C++ application core
- ImGui editor UI
- bgfx viewport rendering
- shared Quader SDK packages for document, tool, selection, session, and viewport math
- thin engine plugins later for importing and baking Quader-authored geometry into Unity, Unreal, Godot, and other hosts

The first milestone is to bootstrap the repository and verify push access.
